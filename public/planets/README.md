- Rutas usadas en `app.js`: `/planets/<nombre>.png` (respetar mayúsculas).
- Si falta una imagen (como la estrella fugaz), el panel muestra el degradado por defecto.
- Tamaño sugerido: cuadrado, mínimo 800×800 px.
